# File Review Studio

フォルダをまるごと読み込んで、**構造・関係・中身をその場でレビューする**ためのビューアです。

- **ファイルは端末から出ません。** すべてブラウザの中だけで処理します。サーバーへの送信は一切ありません
- サーバー不要・アカウント不要・完全無料
- 初見のプロジェクトを「どこから読めばいいか」から案内します

---

## できること

### 読む
| | |
|---|---|
| Markdown | 目次つきで整形。Mermaid 記法は図として描画、罫線で描いた図は等幅グリッドを補正して表示 |
| ソースコード | 構文ハイライト、行番号、関数・クラスのアウトライン。何万行あっても仮想スクロールで軽い |
| CSV / TSV | 並べ替え・絞り込みに加えて、列ごとの型と欠損率を表示 |
| PDF / Word | ページ送りしながら閲覧（重いライブラリは開いたときだけ読み込む） |
| 画像 / その他 | プレビュー、または保存 |

### 調べる
- **全文検索** — 入力しながら結果が出る。正規表現・単語一致・大文字小文字・対象ファイルの絞り込みに対応
- **ファイル内検索**（Ctrl+F）
- **関係グラフ** — 参照のつながりを俯瞰。ドラッグ・ズーム・ノードを掴んで固定
- **ファイルの比較** — 2 つのファイルの差分を左右の行番号つきで表示

### 気づく（このアプリならではの機能）
- **読む順番の提案** — 依存関係をたどり、理解の足場になる順に並べる
- **リンク切れの検出** — ドキュメントに書かれているのに存在しないパス
- **循環参照の検出**
- **孤立ファイルの検出** — どこからも参照されていないファイル
- **役割の推定** — フォルダ名・ファイル名から「何をする場所か」を推し量って表示
- **アーキテクチャ図の生成** — 依存関係から Mermaid 図を組み立て、そのまま資料に貼れる

### 記録する
- 行ごとの**メモ**（「要確認」の印つき）
- ファイル単位の**確認済み**チェックと進捗
- **レビューレポート**を Markdown / 単体で開ける HTML で書き出し
- 記録はブラウザ内（IndexedDB）に保存され、次に開いたときも残っています

### 使い心地
- ライト / ダークテーマ（OS 設定への追従も可）
- 文字サイズ・行間・本文幅の調整
- タブのピン留めとドラッグ並べ替え、左右分割ビュー
- コマンドパレット（Ctrl+Shift+P）とクイックオープン（Ctrl+P）
- キーボードだけでツリーを辿れる。コントラストは WCAG AA を満たす

## キーボード操作

| キー | 動作 |
|---|---|
| `Ctrl` + `P` | ファイルをすばやく開く |
| `Ctrl` + `Shift` + `P` | コマンドを実行 |
| `Ctrl` + `Shift` + `F` | 全文検索 |
| `Ctrl` + `F` | 開いているファイルの中を検索 |
| `Ctrl` + `B` | サイドバーの表示切替 |
| `Ctrl` + `\` | 画面を左右に分ける |
| `Ctrl` + `Enter` | 今のファイルを確認済みにする |
| `Ctrl` + `W` | タブを閉じる |
| `Ctrl` + `Tab` | 次のタブ |
| `Ctrl` + `+` / `-` / `0` | 文字を大きく / 小さく / 元に戻す |
| `F5` | フォルダを読み直す（対応ブラウザのみ） |

## 開発

```bash
pnpm install
pnpm dev            # http://localhost:5180
```

開発中はブラウザのコンソールで `__loadDemo()` と打つと、見本プロジェクトを読み込めます。

### ビルド

```bash
pnpm build          # dist/        通常ビルド（PWA つき・GitHub Pages 用）
pnpm build:single   # dist-single/ 単一 HTML（ダブルクリックで開ける持ち運び用）
```

- **通常ビルド** — コードを分割し、PDF・Word・図の描画は使うときだけ読み込みます。Service Worker が付くので、一度開けば次からオフラインでも起動します
- **単一 HTML ビルド** — すべてを 1 ファイル（約 4.5 MB）に埋め込みます。USB メモリに入れて配る、といった使い方向け

### 公開（GitHub Pages）

1. GitHub にリポジトリを作って push
2. Settings → Pages → Source を **GitHub Actions** に変更

以降は `main` に push するたびに `.github/workflows/deploy.yml` が動き、
`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
URL を開くだけなので、他の PC でもインストール不要で使えます。

## 構成

```
index.html            画面の骨組み
src/
  main.js             起動と配線（キー操作・コマンド・読み込みの流れ）
  core/
    state.js          共有する状態とイベント
    util.js           パス・種別判定などの小道具
    roles.js          ファイル・フォルダの役割の推定
    ingest.js         フォルダの読み込み（進捗つき）
    analyze.js        参照関係の解析・リンク切れ・循環・読む順番
    outline.js        コードの見出し抽出
    diff.js           行単位の差分
    review.js         レビューの記録
    persist.js        保存（IndexedDB / localStorage）
  ui/                 サイドバーの各パネル・タブ・パレット・設定
  viewers/            種類ごとの表示（コード / Markdown / CSV / PDF / 図 / 差分 …）
  styles/             デザイントークンと各画面のスタイル
```

色は `src/styles/tokens.css` に集約しています。`light-dark()` で
ライトとダークの値を 1 行にまとめているので、片方だけ直して食い違う心配がありません。

## 動作環境

Chrome / Edge を推奨します（フォルダを覚えておく機能が使えるため、
次回から一覧をクリックするだけで開き直せます）。
Firefox / Safari でも読み込みと閲覧はできますが、フォルダの記憶はできません。
