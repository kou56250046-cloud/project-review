# フロー記法（```flow）を図として描く — 要件（規模 M）

## 背景

gemini-kit（`bunsekiya-manage/gemini-kit`）は、Gemini に書かせた ```flow コードブロックを
スイムレーン付きの SVG フロー図に描いている（`src/js/flow.js`）。記法の定義は
`gemini-kit/src/items/50-fmt-flow.md`。同じ md を本ツールで開くとただのコードブロックとして出る。

## 受入条件

1. Markdown / Word 中の ```flow ブロックが、gemini-kit と同じ配置・配色の SVG フロー図で表示される
2. 言語指定なし・`text` 系で、記法として正しく読める（エラー0・ノード2以上・矢印1以上）ブロックも図にする
3. ヘッダーの「フロー／原文」で記法の原文に切り替えられ、コピーできる
4. 記法にエラーがあるときは原文だけを出し、ラベルに「描画できませんでした」、title にエラー内容を出す
5. ダークテーマでは図の面を白い紙として表示し、読める
6. 既存の罫線図・ツリー・レイヤーカード・Mermaid の表示は変わらない
7. 新しい依存を足さない

## 非目標

- フロー図のダークテーマ配色、配色・レイアウトの変更
- gemini-kit 側との共通化（パッケージ化）。コピー移植で済ませる
- `.flow` 拡張子のファイル単体を図で開くこと
- PPTX 出力・図の編集・SVG ダウンロード
- 既存の `parseFlowDiagram`（罫線図→フロー図）や Mermaid の挙動変更
